使用场景

跨境办公与远程会议

文档同步、代码仓库和视频会议对延迟抖动敏感。红杏旗舰版与团队版提供更干净的专线节点，适合把加速器固定在工作设备上，白天走办公分流，晚上再切流媒体策略。

课程资料与学术检索

高校与研究场景常需要稳定打开外文期刊、公开课和软件源。基础版 100GB 足够浏览与下载讲义；若需同时开多台电脑或平板，可直接升级到支持更多在线设备的套餐。

流媒体与内容创作校对

旗舰版强调全节点原生流媒体解锁，减少片源地区限制带来的反复缓冲。创作校对、字幕对照时，建议关闭全局游戏规则，只对媒体域名走代理，把流量留给正片。

游戏加速

IPLC 专线针对对延迟敏感的对战与登录排队。红杏不把游戏加速写成万能加速器，实际体验仍取决于运营商线路与所选节点距离，建议在非高峰先测延迟再锁定节点。

操作说明（纵向步骤）

按下面五步即可完成从打开官网到成功连接。每一步只做一件事，避免同时修改系统代理和客户端配置。

  1. 1打开红杏官网并确认套餐。对照流量、设备数和是否需要 IPLC、原生流媒体，选择基础版、旗舰版或团队版。年付适合长期使用同一订阅。
  2. 2完成订购后复制订阅地址。订阅地址仅保存在你自己的密码管理器或系统备忘录，不要发到群聊或截图外传。团队版如需多人使用，由客户经理分配独立凭证。
  3. 3下载对应系统的客户端。前往本页客户端下载一节，按 iOS、Android、Windows、macOS 选择应用。只使用官网列出的导入方式，勿安装来路不明的修改包。
  4. 4在客户端粘贴订阅并更新节点。Clash 系选择订阅 URL，Shadowrocket 与 Quantumult X 使用安装配置，v2rayN 使用订阅分组。更新成功后应看到红杏节点列表，而不是空白或过期提示。
  5. 5选择规则模式后连接。日常浏览用规则分流，仅对需要加速的域名走代理；视频或游戏再切对应策略组。连接后打开目标站点验证，再去看常见问题里的排障条目。

客户端下载与官方导入

红杏本身提供订阅，不捆绑闭源加速器安装包。请在各系统官方应用渠道获取客户端，再回到本页按步骤导入。以下为官网推荐的下载与导入对应关系。

手机端

iOS 使用 Shadowrocket 或 Quantumult X：在应用内添加订阅，开启规则分流。Android 使用 Clash Meta 系列：导入 YAML/订阅链接后开启服务，并在系统设置中允许 VPN 配置。

电脑端

Windows 推荐 v2rayN 或 Clash 图形客户端，macOS 可用 Clash Verge 或 Surge。导入后检查系统代理端口是否被其他软件占用。企业环境如需固定出口，使用团队版定制路由，而不是在每台电脑手动改 hosts。

常见问题

红杏把高频疑问集中展示。展开即可阅读完整回答，无需离开本页。

红杏是什么？和普通加速器有何不同？

红杏是机场订阅品牌：你购买的是流量与节点权限，再通过主流客户端连接。它不是单一封装的加速器 App。好处是同一订阅可在手机、电脑间复用；代价是需要按官方步骤完成一次导入。若你只想要三台设备、每月约 100GB，基础版即可；需要原生流媒体和游戏专线再看旗舰版。

如何完成官网下载并导入订阅？

先在套餐区选定版本，获取订阅地址，再进入本页客户端下载一节选择系统对应软件。导入时粘贴完整 HTTPS 订阅链接，点击更新。若列表为空，检查是否漏了令牌、是否用了过期截图里的旧地址。不要把订阅填进浏览器地址栏直接打开，那不会完成客户端配置。

三个套餐应该怎么选？流量用完会怎样？

个人轻度浏览选基础版；需要 5 台设备、原生流媒体和 IPLC 选旗舰版；工作室或多成员选团队版。月流量用尽后连接会降速或暂停，视当期策略而定，不会自动扣费升级。年付只是预付折扣，不额外赠送设备位。需要更多流量应升级套餐而不是反复开关节点。

红杏支持哪些流媒体和游戏场景？

基础版覆盖常见影视站点的基础解锁；旗舰版强调全节点原生解锁，适合长期观看与校对。游戏方面，IPLC 对登录和匹配更友好，但不能保证所有区服低延迟。若某条线路高峰拥堵，在客户端切换同区域备用节点即可，不必反复重装软件。

设备数超限或多人共用怎么办？

同时在线超过套餐设备上限时，新设备可能无法握手。先在已登录设备里断开，再连接新终端。家庭共用优先旗舰版 5 设备；公司或社团使用团队版 20 设备，并由专属客户经理划分路由，避免所有人挤在同一普通节点。

连接成功但打不开网页，如何排查？

按顺序检查：客户端是否真的处于已连接、系统时间是否准确、是否开了与其他代理冲突的全局模式、DNS 是否被浏览器插件改写。可先切规则模式访问普通网页，再测目标站点。仍失败时，旗舰版与团队版可通过优先工单提交节点名称、客户端版本和发生时间，不要只发“连不上”三个字。
